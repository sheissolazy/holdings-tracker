# 《囤货少女的末日恋爱》游戏机制设计（v0.1 待敲定）

> 一句话：**《苏丹的游戏》的骨架（每周抽一张"必须在 7 天内解决的卡"+ 地图放卡 + 骰子检定 + 多线结局），换成"女生在末日前夜囤货、经营小窝、和幸存者谈恋爱"的皮。**
>
> 本文档是给你拍板用的。每一节末尾有 `[待定]` 标记的，是需要你做决定的点；其余是我的推荐默认值，你不反对就按这个做。

## 0. 参考作品机制拆解（已核实）

《苏丹的游戏》核心机制（来源见文末）：

| 苏丹的游戏 | 机制要点 |
|---|---|
| 苏丹卡 | 每周抽 1 张，分 杀戮/纵欲/奢靡/征服 四类，石/铜/银/金 四档。**7 天内必须"折卡"（做一件同类且品质≥卡的事），否则斩首。** 28 张一副。|
| 回合 | 以**天**为单位。每天把卡放进地图上的事件槽位，事件耗 1~N 天，**次日清晨结算**。|
| 卡牌 | 苏丹卡、人物卡、思潮卡、消耗品、部队、情报、装备、书籍、食物…共 10 类，都分四档品质。|
| 检定 | **骰子数 = 相关属性之和**（如 智力+社交），数成功数；成功数分档给不同结果（≥3 大成功 / 2 / 1 / 0）。|
| 经济 | 金币是硬通货，每回合固定有几个金币消耗点（书店、上朝、浴场）。装备商人 7 天换一次货。|
| 结局 | 多条主线（逃亡/屠龙/反叛/神线），多周目解锁"命运商店"。|

**我们抄的是"骨架"这四样：**
1. 每周一张倒计时压力卡（不解决=惨）
2. 地图 + 事件 + 卡槽（把人/物放进去）
3. 属性=骰子数的检定
4. 天→周→局 的三层节奏，多线结局

**我们换掉的：** 宫廷阴谋 → 末日前夜的城市；杀人纵欲 → 囤货、修窝、谈恋爱；斩首 → "没撑过这周"。

## 1. 题材与基调

- **主角**：25 岁左右的普通上班族女生，独居公寓。某天开始察觉"要出事"（新闻、断供、物价异常）。
- **世界**：末日**渐进式**到来，不是一夜丧尸。分三个阶段：**前夜（1~3 周）→ 崩塌（4~7 周）→ 新秩序（8~10 周）**。前期还能刷卡买东西，中期钱变废纸、以物易物，后期社区自治。
- **恋爱**：4~5 位可攻略幸存者（男女皆可 `[待定]`），每人一条剧情线，好感高到一定程度会"搬进来一起住"，带来他的物资、技能和麻烦。
- **基调**：**丧萌 + 温情 + 一点点紧张**。不血腥，无成人内容。文案风格参考"末日日记"体，每天一条主角内心 OS。`[待定：要不要更黑暗一点，比如允许角色死亡]`

## 2. 核心循环

```
一局（10 周）
 └─ 一周（7 天）：周一抽 1 张【危机卡】，周日夜结算
      └─ 一天：
           1. 清晨：结算昨日事件，发新闻/消息，扣每日消耗
           2. 白天：把"主角卡 + 同伴卡 + 物资卡"放进地图上的事件槽（主角一天只能在一处）
           3. 点"过一天"
```

### 2.1 一天做什么

- 地图上有 8~12 个**地点**（家、超市、药店、五金/户外店、二手市场、小区群、公司、快递站、医院、加油站、郊区农场…）。
- 每个地点下挂 1~3 个**事件**（"抢购矿泉水""跟邻居换东西""帮他修发电机"）。
- 每个事件有**卡槽**：红槽必填（一般是主角或某个 NPC），白槽选填（放物资/情报/道具加骰子或改结果）。
- **主角一天只能进一个事件**；同伴（好感≥某档的 NPC）可以单独去别的事件（这是恋爱线和资源线互相咬合的关键：让他去帮你跑腿，就没时间陪你）。
- 事件耗时 1~3 天，**次日清晨结算**，弹结果卡（文案 + 得到/失去的卡）。

### 2.2 一周做什么：危机卡（= 苏丹卡）

每周一抽一张危机卡，**7 天内必须"顶住"**，否则本周结算时受重创。

四类危机 × 四档强度：

| 类型 | 对应囤货维度 | 例子（石→金） |
|---|---|---|
| 🍞 **匮乏** | 食物 / 水 | 超市限购 → 断水两天 → 全区断供一周 → 饥荒 |
| ❄️ **气候** | 能源 / 保暖 | 降温 → 停电一晚 → 暴雪封路 → 极寒 |
| 🦠 **疫病** | 药品 / 卫生 | 流感 → 邻居确诊 → 小区封控 → 你自己发烧 |
| 🔥 **动荡** | 安全 / 防御 | 小偷 → 楼道被撬 → 暴徒扫楼 → 武装抢劫 |

**顶住的方式（= 折卡）：**
1. **硬顶**：在周日夜前，仓库里对应维度的物资**总品质分 ≥ 危机分**（石=1 铜=2 银=4 金=8），结算时消耗其中一部分。
2. **借力**：某些 NPC 有"危机技能"（医生顶疫病、退伍兵顶动荡），好感够且他在家，可以**代替**硬顶一次（消耗他的一张技能卡，并推进他的剧情）。
3. **剧情解**：完成该周专属的剧情事件（例如"帮全楼组织互助群"顶住动荡卡）。

**顶不住的后果**（按强度）：石=扣心态+丢一批物资；铜=主角生病 3 天不能行动；银=同伴离开 / 家被洗劫；金=**Game Over（本局结束进结算）**。`[待定：金卡失败是否直接结束]`

危机牌堆：一局 10 周共抽 10 张，牌堆按阶段加权——前夜多石/铜，崩塌多银，新秩序必出 1 张金。玩家能提前 1 周看到"下周预警"（情报卡可以看更远）。

### 2.3 一局做什么

10 周后按"存活状态 + 好感 + 社区声望"进结局。中途失败也进结局（坏结局）。每局 60~90 分钟一遍。`[待定：10 周还是 12 周]`

## 3. 卡牌系统

所有东西都是卡，都有四档品质（石/铜/银/金）。

| 类型 | 说明 | 例子 |
|---|---|---|
| **主角卡** | 唯一，带 4 属性 + 状态 | 你 |
| **人物卡** | 可攻略 NPC + 普通 NPC（邻居、店员、大妈） | 隔壁程序员阿哲、社区医生林晚、退伍军人老K、便利店店员小鱼、网红主播Vivi |
| **物资卡** | 分 6 个维度：食物、水、药品、能源、安全、日用；**食物/药品有保质期** | 一箱矿泉水(铜/水)、压缩饼干(银/食物)、发电机(金/能源)、防盗门加固(银/安全) |
| **情报卡** | 一次性，用于预知/改结果 | "内部消息：下周超市停业"（提前看到下下周危机） |
| **技能卡** | NPC 好感解锁，可代替硬顶或加骰子 | 林晚的"急救"、老K的"守夜" |
| **心情卡** | 恋爱线产物，给主角/NPC 加状态 | "他昨晚留下的便签"（本周心态+1） |
| **麻烦卡** | 负面卡，占仓库位，必须处理 | "前任来敲门""房东要涨租""同伴的老母亲" |

### 3.1 仓库与囤货（本作独有的核心张力）

- **仓库容量**：公寓初始 12 格，每张物资卡按体积占 1~3 格。可通过事件扩容（清理储物间 +4、借用邻居家 +3、搬去老K的仓库 +8）。
- **保质期**：食物卡、药品卡带天数，到期变成"过期"卡（品质降一档，再过期变垃圾占位）。逼玩家轮换库存而不是无脑囤。
- **通胀曲线**：钱在前夜阶段好用，每周物价 ×1.3；崩塌阶段起商店只收**以物易物**；新秩序阶段钱彻底作废。逼玩家前期把钱换成东西。
- **每日消耗**：主角每天吃 1 份食物 + 1 份水；同伴同住每人再 +1。没吃就掉健康。

### 3.2 属性与检定（抄苏丹）

主角 4 属性，初始各 1~3 点，一局内通过事件成长：

| 属性 | 用途 |
|---|---|
| 💪 **体力** | 搬货、跑腿、守夜 |
| 🔧 **手艺** | 修东西、改装、种菜 |
| 🧠 **头脑** | 分析情报、砍价、算账 |
| 💬 **魅力** | 社交、求助、恋爱事件 |

**检定 = 掷 (属性A + 属性B + 白槽加成) 个骰子，每个骰子 50% 成功，数成功数：**
- 0 成功：失败（拿石级 / 触发麻烦）
- 1~2 成功：普通（拿铜级）
- 3~4 成功：良好（拿银级）
- ≥5 成功：大成功（拿金级 / 触发隐藏剧情）

NPC 人物卡也有这 4 属性，放进同一事件时属性相加（这就是"带他一起去"的动机）。

## 4. 恋爱系统

- 每位可攻略 NPC 有**好感 0~100**，分 5 档：陌生 → 熟人 → 朋友 → 暧昧 → 恋人。
- 涨好感的方式：一起进事件（+2~5）、送他需要的物资（+5~10，**送出去的东西就没了**——囤货 vs 恋爱的直接冲突）、触发他的专属剧情事件（+10~20）。
- 每档解锁：
  - 熟人：可以来你家串门（触发小事件）
  - 朋友：解锁技能卡；可派他单独去事件
  - 暧昧：可邀请**同住**（带来他的物资 + 每日消耗 +1 + 他的麻烦卡）
  - 恋人：解锁危机"借力"顶卡 + 专属结局
- **多线冲突**：同时对两人好感≥暧昧，会触发"修罗场"事件，检定失败双双掉好感。`[待定：是否允许后宫/开放关系]`
- **NPC 有自己的需求**：每人 1 个"缺的维度"（医生缺能源、退伍兵缺药品…），这决定送什么东西最有效，也决定他搬进来后带什么。

### 4.1 首批可攻略角色（5 人，先定人设，名字随便改）

| 角色 | 身份 | 高属性 | 危机技能 | 缺 | 一句话人设 |
|---|---|---|---|---|---|
| 阿哲 | 隔壁程序员 | 头脑 | 情报（预知危机） | 食物 | 社恐宅男，末日了还在远程上班 |
| 林晚 | 社区医生 | 手艺/头脑 | 顶疫病 | 能源 | 冷静温柔，一直在超负荷工作 |
| 老K | 退伍军人/保安 | 体力 | 顶动荡 | 药品 | 话少，靠谱，有个不能说的过去 |
| 小鱼 | 便利店店员 | 魅力 | 折扣/补货 | 安全 | 元气少女，掌握全城货源八卦 |

## 5. 主角状态

- **健康** 0~10：饿、冷、病会掉；归零 = Game Over。
- **心态** 0~10：危机失败、孤独、麻烦卡会掉；<3 时每次检定 -1 骰；恋爱事件回复。
- **声望** 0~100：小区里的口碑，影响以物易物汇率和社区结局。

---

## 6. 结局（首版 7 个）

1. **独活**：10 周活下来，无恋人。
2~6. **双人结局 ×5**：与某人恋人档 + 同住 + 通关。每人一段独立结局文本。
7. **社区领袖**：声望≥80 + 通关（可与双人结局叠加）。
- 坏结局：健康归零 / 金卡失败 → "没撑到春天"，显示本局统计。

**多周目**：通关解锁"记忆碎片"，下一局可选一个开局加成（多 4 格仓库 / 某 NPC 初始好感 20 / 初始多 1 属性点）。

## 9. 技术方案

- **栈**：React 18 + Vite + TypeScript + Tailwind v4（和你现有仓库一致，Codex 和我都熟；纯静态，可以直接部署 GitHub Pages，手机能玩）。
- **架构**：**引擎与内容分离，引擎与 UI 分离。**
  ```
  src/
    engine/        纯 TS，无 React：状态机、结算、检定、危机、仓库、好感（可单元测试，带 seed 的随机数）
    content/       纯数据：地点/事件/卡牌/NPC/文案（JSON 或 TS 对象，按 schema 校验）
    ui/            React 组件：地图、卡槽拖放、仓库、日记、结算弹窗
    save/          localStorage 存档 + 多周目解锁
  ```
- **内容 schema 先定**（事件 = 条件 + 槽位 + 检定 + 结果分支），之后写内容就是填表，也方便后面用 LLM 批量生成文案再人工筛。
- **确定性**：所有随机走 seeded RNG，方便复现 bug 和做自动化"跑一千局"平衡测试。
- **不做**：后端、账号、联机、复杂动画（首版用文字 + 简单卡面 + emoji/占位图）。

## 11. Claude × Codex 协作方式

**先说实话**：这个云端会话里**没有装 Codex CLI，也没有 OpenAI 密钥**，我没法直接在这里调用 Codex。可行的协作模式是：

- **我（Claude）负责**：架构与 schema、`engine/` 核心与单元测试、平衡模拟脚本、代码评审、合并冲突、每个里程碑的验收。
- **Codex 负责**（你在本地或 Codex 云端跑，指向同一个仓库）：`ui/` 组件、`content/` 批量内容填充、样式与动效。
- **对接方式**：仓库根放 `AGENTS.md`（Codex 读）和 `CLAUDE.md`（我读），写同一套约定：目录边界、schema、命名、"改引擎必须过测试"、提交规范。每个任务写成 `docs/tasks/T-xxx.md`，谁领谁改状态。**你负责当"项目经理"把任务 ID 丢给 Codex**，我这边每次开会话先 `git pull` 看它做了什么再继续。
- **边界规则**：Codex 不改 `engine/` 的公开接口；我不改 `ui/` 的视觉决策。改 schema 必须先改文档再改代码。
